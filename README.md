# ?? NDS R4 Ultimate Repository

Este repositorio contiene la configuración, herramientas y documentación necesaria para crear el setup definitivo en una flashcard R4 para Nintendo DS.

## ?? Estructura del Proyecto

*   **/docs**: Guías detalladas, lista de recursos y planes de desarrollo.
    *   [MANUAL.md](docs/MANUAL.md): Guía maestra de instalación.
    *   [RECURSOS.md](docs/RECURSOS.md): Enlaces a emuladores, homebrew y wikis.
    *   [AUTOBUILD.md](docs/AUTOBUILD.md): Plan de automatización.
*   **/templates**: Archivos base y configuraciones para la MicroSD.
*   **/scripts**: Scripts de automatización (en desarrollo).
*   **/archive**: Resguardos temporales.
